Projet principal du stage : concevoir une infrastructure réseau complète incluant un système de monitoring intelligent capable d'analyser automatiquement les anomalies détectées et d'envoyer un diagnostic par email — sans intervention humaine.

L'architecture repose sur OPNsense comme pare-feu, Zabbix pour la supervision, et un agent IA Flowise connecté à un modèle de langage (LLM) pour l'analyse et la recommandation.

Réalisations

  • Portail captif WiFi RGPD — développé de A à Z sur OPNsense (base de données, interface d'administration) : consentement éclairé, export des emails collectés, droit à l'oubli via token, nettoyage automatique des données anciennes — une offre que LOXYS ne proposait pas encore à ses clients avant ce projet
  • Supervision centralisée — Zabbix 7.0 sous Docker Compose, agents sur 3 hôtes (serveurs Ubuntu + OPNsense)
  • API de monitoring — scripts Python Flask exposant les métriques CPU, RAM, disque, température
  • Agent IA — Flowise + Groq (llama-3.3-70b), mémoire tampon et 5 itérations maximum, connecté à 2 outils custom : métriques live et diagnostic SSH restreint
  • Alertes automatiques — webhook Zabbix → analyse IA → email HTML avec diagnostic et marche à suivre
  • Sécurité SSH — compte dédié sans sudo, clé Ed25519, commande forcée en lecture seule

Problèmes résolus

  • Intégration des outils personnalisés — l'agent IA n'appelait pas correctement les outils Flowise ; correction du schéma des Custom Tools et redémarrage du service
  • Fiabilité des réponses — tendance de l'agent à générer des diagnostics génériques ; corrigé en forçant l'appel systématique des outils de métriques réelles avant analyse
  • Conflit de ports — l'interface web Zabbix et le portail captif se disputaient le même port ; séparation sur deux ports distincts
  • Compatibilité Zabbix / Ubuntu — la version LTS utilisée n'était pas supportée par le dépôt Zabbix par défaut ; identification du bon dépôt
  • Timeout des alertes — les webhooks expiraient avant la réponse de l'agent IA ; ajustement du délai d'exécution des scripts
