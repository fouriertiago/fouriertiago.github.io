Serveur de téléphonie IP Wazo

Installer pour LOXYS un serveur de téléphonie sur IP (IPBX) Wazo Platform sur une machine virtuelle Debian 12, le vérifier avec des softphones et le rattacher à la supervision Zabbix.

PériodeOctobre 2026CadreAlternanceEnvironnementDebian 12 sur VMware
ContexteRéalisationTestsSupervisionPiste étudiéeCompétences E5Preuves

Contexte

Dans le cadre de mon alternance chez LOXYS, j'ai monté un serveur de téléphonie sur IP avec Wazo Platform, une solution open source qui joue le rôle d'autocommutateur (IPBX) : elle gère les comptes, les numéros internes et les appels entre postes et softphones.

Réalisation

  1. Machine virtuelle — création d'une VM Debian 12 sur l'infrastructure VMware de LOXYS.
  2. Installation — déploiement de Wazo Platform avec wazo-ansible, l'installation automatisée par playbooks Ansible.
  3. Configuration — création d'un contexte interne avec la plage de numéros 1000 à 1099, et d'utilisateurs de test.

Tests

Les utilisateurs de test ont été configurés sur trois softphones différents : MicroSIP, Linphone et Zoiper, pour vérifier que le serveur fonctionne avec plusieurs clients.

Supervision

J'ai installé l'agent Zabbix (version 7.4) sur la VM, pour que le serveur de téléphonie soit suivi par la supervision, comme les autres serveurs.

Piste étudiée

Je m'intéresse au mode multi-tenant de Wazo, qui permettrait de gérer plusieurs clients isolés les uns des autres sur une même plateforme.
